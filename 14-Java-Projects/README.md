# មេរៀនទី ១៤៖ គម្រោង Java

គម្រោងជួយភ្ជាប់ syntax ទៅការរចនាកម្មវិធីពិត។ ជ្រើសគម្រោងតាមកម្រិត ហើយបញ្ចប់តាមដំណាក់កាល៖ requirement → design → implementation → tests → documentation → package/run។

## គម្រោងកម្រិតដំបូង
- **Console calculator**៖ input validation, methods, conditions។
- **Student score manager**៖ arrays/collections, average, search។
- **File-based contact book**៖ classes, collections, file I/O, exceptions។

## គម្រោងកម្រិតមធ្យម
- **Library manager**៖ OOP, interfaces, collections, persistence file។
- **Expense tracker**៖ categories, date handling, reports, CSV export។
- **JDBC inventory**៖ relational schema, CRUD, PreparedStatement, transactions។

## គម្រោងកម្រិតខ្ពស់
- **Concurrent job processor**៖ ExecutorService, bounded queue, cancellation, graceful shutdown។
- **HTTP client**៖ Java HttpClient, timeout, status/error handling, JSON library។
- **Spring Boot REST API**៖ database, validation, tests, security, observability និង deploy។

## វិធីវាយតម្លៃគម្រោង
1. សរសេរ requirement និង acceptance criteria។
2. បំបែក domain model ពី I/O និង user interface។
3. ប្រើ input validation និង error handling។
4. បន្ថែម unit/integration tests។
5. រក្សា secret ក្រៅ source control។
6. សរសេរ README របៀប build, run, test និង limitation។
7. បង្ហាញ sample input/output និង known issues។
