# លំហាត់មេរៀនទី ៧៖ Arrays

សូមសាកល្បងសរសេរកូដដោយខ្លួនឯងជាមុនសិន។ ចម្លើយគំរូមាននៅក្នុង [Answer.java](Answer.java)។

## លំហាត់ទី 1៖ បង្កើត Array

បង្កើត Array ឈ្មោះ `numbers` ដែលមានតម្លៃ៖ 5, 10, 15, 20, 25។

បង្ហាញតម្លៃនៅ Index 0, Index 2 និង Index 4។

លទ្ធផល៖

```text
5
15
25
```

## លំហាត់ទី 2៖ កែប្រែតម្លៃ

បង្កើត Array៖

```java
int[] ages = {18, 20, 22, 24};
```

ប្តូរតម្លៃនៅ Index 1 ទៅជា 21 រួចបង្ហាញធាតុទាំងអស់។

## លំហាត់ទី 3៖ For Loop

បង្កើត Array ដែលមានលេខ 2, 4, 6, 8, 10។ ប្រើ `for` Loop ដើម្បីបង្ហាញតម្លៃទាំងអស់។

## លំហាត់ទី 4៖ For-Each Loop

បង្កើត String Array ដែលមានឈ្មោះផ្លែឈើ 4 ប្រភេទ។ ប្រើ `for-each` ដើម្បីបង្ហាញឈ្មោះផ្លែឈើទាំងអស់។

## លំហាត់ទី 5៖ គណនាផលបូក

បង្កើត Array៖

```java
int[] prices = {10, 20, 30, 40, 50};
```

ប្រើ Loop ដើម្បីគណនាផលបូកទាំងអស់ ហើយបង្ហាញលទ្ធផល។

លទ្ធផល៖

```text
Total: 150
```

## លំហាត់ទី 6៖ គណនាមធ្យមភាគ

បង្កើត Array ពិន្ទុសិស្ស៖ 70, 80, 90, 85, 75។

គណនាមធ្យមភាគដោយប្រើ៖

`average = total / array.length`

សូមប្រើ `double` ដើម្បីទទួលបានលទ្ធផលទសភាគ។

## លំហាត់ទី 7៖ Two-Dimensional Array

បង្កើត 2D Array ដែលមានតម្លៃ៖

```text
1 2 3
4 5 6
```

ប្រើ Nested Loop ដើម្បីបង្ហាញតម្លៃទាំងអស់ដូចក្នុងរូបភាពខាងលើ។
