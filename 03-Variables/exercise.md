# លំហាត់មេរៀនទី ៣៖ Variables and Data Types

សូមសាកល្បងធ្វើលំហាត់ដោយខ្លួនឯង មុនពេលមើលចម្លើយក្នុង `Answer.java`។

## លំហាត់ទី ១៖ បង្កើត Variables

បង្កើត file ឈ្មោះ `MyInformation.java` ហើយប្រកាស variables ខាងក្រោម៖

1. ឈ្មោះរបស់អ្នក ដោយប្រើ `String`។
2. អាយុ ដោយប្រើ `int`។
3. កម្ពស់ ដោយប្រើ `double`។
4. អក្សរថ្នាក់ ដោយប្រើ `char`។
5. តើអ្នកជានិស្សិតឬទេ? ដោយប្រើ `boolean`។

បន្ទាប់មកប្រើ `System.out.println()` ដើម្បីបង្ហាញតម្លៃទាំងអស់។

## លំហាត់ទី ២៖ ជ្រើសរើស Data Type

ជ្រើសរើស data type ដែលសមស្របសម្រាប់តម្លៃនីមួយៗ៖

1. ចំនួនសិស្សក្នុងថ្នាក់ = 35
2. តម្លៃផលិតផល = 12.75
3. ឈ្មោះទីក្រុង = "Phnom Penh"
4. អក្សរនិទ្ទេស = 'B'
5. តើបានបង់ប្រាក់ហើយឬនៅ? = true

## លំហាត់ទី ៣៖ រកកំហុស

សូមពន្យល់ថាកូដខាងក្រោមខុសត្រង់ណា ហើយកែឱ្យត្រឹមត្រូវ៖

```java
int age = "20";
String name = 'Sokha';
float price = 10.5;
int 2score = 90;
```

## លំហាត់ទី ៤៖ Constant

1. បង្កើត constant ឈ្មោះ `TAX_RATE` ដែលមានតម្លៃ `0.10` ដោយប្រើ `final`។
2. ពន្យល់ថាហេតុអ្វីយើងមិនអាចប្តូរតម្លៃ constant នោះបន្ទាប់ពីកំណត់រួច។

## លំហាត់បន្ថែម

បង្កើតកម្មវិធីមួយដែលរក្សាទុកព័ត៌មានផលិតផល៖ ឈ្មោះផលិតផល តម្លៃ ចំនួនក្នុងស្តុក និងថាតើមានក្នុងស្តុកឬអត់។ បន្ទាប់មកបង្ហាញព័ត៌មានទាំងអស់លើ Terminal។
