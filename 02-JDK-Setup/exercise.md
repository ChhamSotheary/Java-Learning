# Lesson 02 - Exercises

Complete these tasks on your own computer.

## Exercise 1: Check your JDK

Open PowerShell or the VS Code terminal and run:

```powershell
java -version
javac -version
```

Write down the version information displayed by both commands.

## Exercise 2: Install the tools

- [ ] Install a JDK (prefer an LTS release).
- [ ] Install Visual Studio Code.
- [ ] Install Microsoft's Extension Pack for Java.
- [ ] Open a folder named `JavaPractice` in VS Code.

## Exercise 3: Run the example

1. Create `SetupCheck.java`.
2. Type the example from this lesson.
3. Compile it using `javac SetupCheck.java`.
4. Run it using `java SetupCheck`.
5. Confirm that the output matches the lesson.

## Exercise 4: Answer in your own words

1. What is the JDK?
2. Why do we need `javac`?
3. What does `java -version` show?
4. Why should the public class name match the Java file name?
5. What is the purpose of the Java extensions in VS Code?

## Challenge

Change the program so it prints your name, your country, and this sentence:

`I am learning Java programming.`
