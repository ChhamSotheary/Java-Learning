# លំហាត់មេរៀនទី ៩៖ Class និង Object

1. បង្កើត class Book ដែលមាន title, author និង pages។
2. បង្កើត constructor ទទួល field ទាំងបី។
3. បង្កើត method printInfo() ដែលបង្ហាញព័ត៌មានសៀវភៅ។
4. បង្កើត object ពីរ ហើយបង្ហាញព័ត៌មាន។
5. ពន្យល់ភាពខុសគ្នារវាង class និង object និងតួនាទីរបស់ this។
6. Challenge: បន្ថែម method isLongBook() ដែលត្រឡប់ true បើ pages លើស 300។
