# Spring Boot Learning — មេរៀនលម្អិតជាភាសាខ្មែរ

ផ្លូវរៀននេះបន្តពី Java មូលដ្ឋានទៅការបង្កើត web service ដែលអាចសាកល្បង សង្កេត និង deploy បាន។ Spring Boot បន្ថយការកំណត់ infrastructure ដោយប្រើ starters និង auto-configuration ប៉ុន្តែអ្នកនៅតែត្រូវយល់ពី bean lifecycle, HTTP, database, security និង runtime។

## មុនចាប់ផ្ដើម
រៀន Java classes/interfaces, exceptions, collections, generics និង build tool មូលដ្ឋាន។ បង្កើត project ដោយ Spring Initializr និងជ្រើស JDK/framework version ដែលនៅ stable/supported តាមពេលចាប់ផ្តើម។ សូមប្រើ documentation version ដូច project របស់អ្នក ព្រោះ API និង dependency អាចផ្លាស់ប្តូរ។
