## How to run Java code

Install a Java Development Kit (JDK), then open a terminal in the folder containing the source file.

```bash
javac HelloWorld.java
java HelloWorld
```

## Learning method

- Read each lesson carefully.
- Type the examples yourself.
- Run the programs and observe the output.
- Complete the exercises before checking the solutions.
