## How to Run Java

Install a JDK, open a terminal in the folder containing the source file, then compile and run:

~~~bash
javac HelloWorld.java
java HelloWorld
~~~

For Maven/Gradle projects, use the wrapper scripts included in the project.

## Learning Method

- Read each lesson and type the examples yourself.
- Run code and compare actual output with your expectation.
- Complete the exercises before checking sample answers.
- Use a local project or VM for experiments; do not place real credentials or private data in a public repository.
- For advanced topics, record JDK version, assumptions, measurements and what the example does not prove.

## Note on the Advanced Lessons

Topics such as JVM internals, memory model, GC tuning, profiling, security, reactive systems and distributed architecture are publicly documented, but introductory courses often skip them because they require deeper prerequisites and hands-on work. They are included here with practical explanations and safe exercises.
