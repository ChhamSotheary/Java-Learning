# លំហាត់មេរៀនទី ៤៖ Operators

សូមសរសេរកូដដោយខ្លួនឯង ហើយ run ដើម្បីពិនិត្យលទ្ធផល។ កុំមើលចម្លើយមុនពេលសាកល្បង។

## លំហាត់ទី ១៖ Arithmetic Operators

ប្រកាស៖

```java
int x = 17;
int y = 5;
```

សរសេរកូដបង្ហាញ៖

1. លទ្ធផលបូក `x + y`
2. លទ្ធផលដក `x - y`
3. លទ្ធផលគុណ `x * y`
4. លទ្ធផលចែក `x / y`
5. សំណល់ `x % y`

សាកល្បងពន្យល់ថាហេតុអ្វី `x / y` បានលទ្ធផលជាចំនួនគត់។

## លំហាត់ទី ២៖ Comparison Operators

ប្រកាស `int age = 16;`។ បង្ហាញលទ្ធផលនៃការពិនិត្យ៖

1. តើ age ស្មើ 16 ឬទេ?
2. តើ age ធំជាង 18 ឬទេ?
3. តើ age តូចជាង ឬស្មើ 18 ឬទេ?
4. តើ age មិនស្មើ 20 ឬទេ?

## លំហាត់ទី ៣៖ Logical Operators

ប្រកាស variables៖

```java
boolean isStudent = true;
boolean hasCard = false;
```

បង្ហាញលទ្ធផល៖

1. `isStudent && hasCard`
2. `isStudent || hasCard`
3. `!isStudent`
4. ពន្យល់ភាពខុសគ្នារវាង `&&` និង `||`។

## លំហាត់ទី ៤៖ Assignment និង Increment

ចាប់ផ្តើមដោយ `int points = 10;`៖

1. ប្រើ `+= 5` រួចបង្ហាញតម្លៃ។
2. ប្រើ `-= 3` រួចបង្ហាញតម្លៃ។
3. ប្រើ `++` រួចបង្ហាញតម្លៃ។
4. ប្រើ `--` រួចបង្ហាញតម្លៃ។

## លំហាត់ទី ៥៖ គិតលទ្ធផលមុន Run

តើកូដខាងក្រោមបង្ហាញអ្វី?

```java
int a = 4;
int b = 6;
int result = a + b * 2;
System.out.println(result);
```

ហេតុអ្វីបានជាលទ្ធផលបែបនោះ?

## លំហាត់បន្ថែម៖ ពិនិត្យសិទ្ធិចូល

បង្កើតកម្មវិធីមួយដែលមាន៖

- `int age` សម្រាប់អាយុ។
- `boolean hasTicket` សម្រាប់សំបុត្រ។
- ប្រើ `&&` ដើម្បីពិនិត្យថាអ្នកមានអាយុចាប់ពី 18 ឆ្នាំឡើងទៅ និងមានសំបុត្រ។
- បង្ហាញលទ្ធផលជា true ឬ false។
