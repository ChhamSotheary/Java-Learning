# Lesson 01 - Exercises

Try to solve these exercises yourself before opening `Answer.java`.

## Exercise 1: Introduce yourself

Write a Java program that prints:

- Your name
- Your age
- Your country

## Exercise 2: Print multiple lines

Use `System.out.println()` to print these three lines:

```text
I love programming.
I am learning Java.
I will practice every day.
```

## Exercise 3: Understand the code

In your own words, explain:

1. What is a class?
2. What is the main method?
3. What does `System.out.println()` do?
4. What is the difference between JDK and JVM?

## Challenge

Change the `HelloWorld.java` example so that it prints a short welcome message of your own.
