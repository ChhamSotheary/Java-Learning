# លំហាត់មេរៀនទី ១១៖ Collections និង Generics

1. បង្កើត List<Integer> ពីពិន្ទុ 70, 90, 80 ហើយគណនាផលបូក។
2. បង្កើត Set<String> ពីឈ្មោះដែលមានធាតុស្ទួន ហើយរាយចំនួនធាតុតែមួយគត់។
3. បង្កើត Map<String,Integer> សម្រាប់ឈ្មោះ និងពិន្ទុ; រកពិន្ទុតាមឈ្មោះ។
4. តម្រៀប List<Integer> ពីតូចទៅធំ។
5. ពន្យល់ហេតុអ្វី List<int> មិនត្រឹមត្រូវ ហើយ List<Integer> ត្រឹមត្រូវ។
6. Challenge: សរសេរ method ដែលទទួល List<Integer> និង return តម្លៃធំបំផុត; គិតពី list ទទេ។
